# Curriculum Planner

یک وب‌اپلیکیشن Django برای مدیریت برنامه‌های درسی دانشگاهی، اختصاص دادن درس‌ها به گروه‌های درسی و پیگیری پیشرفت دانشجویان برای رسیدن به شرایط فارغ‌التحصیلی.

## هدف پروژه

هدف اصلی این پروژه حل یک مسئله‌ی واقعی و کاربردی برای دانشجویان است: اینکه بتوانند به‌صورت دقیق و ساده بررسی کنند آیا تمام دروس و واحدهای مورد نیاز برای فارغ‌التحصیلی را اخذ کرده‌اند یا خیر.

در واقع، این پروژه به دانشجویان کمک می‌کند تا بدون نیاز به محاسبات دستی و بررسی‌های طولانی، وضعیت خود را در مسیر فارغ‌التحصیلی ببینند، گروه‌های درسی مورد نیاز را مشاهده کنند، پیشرفت خود را پیگیری کنند و در صورت نیاز، تصمیم‌گیری بهتری برای انتخاب دروس آینده داشته باشند.

همچنین، هدف من از توسعه‌ی این پروژه این است که یک پلتفرم کاربردی و قابل‌اعتماد بسازم که:

- دانشجویان بتوانند وضعیت فارغ‌التحصیلی خود را به‌راحتی بررسی کنند
- هر فردی که علاقه‌مند است، بتواند این پروژه را برای دوستان و هم‌دانشگاهی‌های خود اجرا کند
- مدیران و مسئولان آموزشی بتوانند بدون پیچیدگی، برنامه‌ها و آیتم‌های درسی را مدیریت کنند
- داشبورد کاربرپسند و ساده‌ای برای ادمین فراهم شود تا تغییرات و بروزرسانی‌های لازم به‌راحتی انجام شود

## وضعیت فعلی پروژه

این پروژه در حال توسعه است و هم اکنون علاوه بر امکانات دانشجویی، یک پنل مدیریتی سفارشی نیز دارد که به مدیران امکان می‌دهد تا با کمترین پیچیدگی، برنامه‌های درسی را مدیریت کنند.

## امکانات فعلی

- ثبت‌نام، ورود و خروج کاربر
- انتخاب برنامه درسی و داشبورد دانشجو
- فهرست دروس با اطلاعاتی مانند:
  - کد درس
  - نام درس
  - تعداد واحد
  - توضیحات
  - وضعیت فعال/غیرفعال
  - دسته‌بندی
  - ترم پیشنهادی
  - درس اجباری یا اختیاری
  - پیش‌نیازها
- مدیریت گروه‌های درسی:
  - اجباری
  - انتخاب تعداد مشخص
  - انتخاب تعداد واحد مشخص
- پشتیبانی از overflow گروه‌های درسی برای انتقال واحدهای اضافی به گروه دیگر
- پیگیری وضعیت دروس دانشجو:
  - شروع نشده
  - در حال انجام
  - پاس شده
  - مردود
- ثبت نمره
- محاسبه پیشرفت برنامه درسی با در نظر گرفتن:
  - محدودیت گروه‌ها
  - درس‌های اجباری
  - محاسبه‌ی درست واحدهای تکمیل شده
- صفحات وضعیت و چارت برای نمایش وضعیت دانشجو
- پنل ادمین سفارشی برای مدیریت:
  - برنامه‌های درسی
  - گروه‌های درسی
  - درس‌ها
  - اختصاص درس‌ها به گروه‌های درسی با قابلیت drag and drop
- دیتای نمونه برای اجرای نسخه‌ی دمو

## اجرای محلی

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

آدرس‌های قابل‌مشاهده:

- اپلیکیشن دانشجو: http://127.0.0.1:8000/
- پنل ادمین سفارشی: http://127.0.0.1:8000/admin-panel/
- پنل مدیریت Django: http://127.0.0.1:8000/admin/

## داده‌های نمونه (اختیاری)

پس از اجرای migration‌ها:

```bash
python manage.py seed_cs_curriculum
```

این دستور یک برنامه‌ی درسی نمونه برای رشته‌ی علوم کامپیوتر و درس‌های مربوطه ایجاد می‌کند. این دستور کاربر جدید ایجاد نمی‌کند.

## پیکربندی پایگاه‌داده

به‌صورت پیش‌فرض، پروژه از SQLite استفاده می‌کند تا راه‌اندازی برای توسعه بسیار ساده باشد.

اگر بخواهید از PostgreSQL استفاده کنید، این متغیرهای محیطی را تنظیم کنید:

```bash
export DB_NAME=curriculum_planner
export DB_USER=postgres
export DB_PASSWORD=your_password
export DB_HOST=127.0.0.1
export DB_PORT=5432
```

سپس اجرا کنید:

```bash
python manage.py migrate
```

## نکات مهم

- پنل ادمین سفارشی، رابط اصلی مدیریت داده‌های برنامه درسی در این پروژه است.
- منطق overflow گروه‌های درسی و اختصاص درس‌ها در لایه‌ی برنامه‌نویسی مدیریت می‌شود و در محاسبات پیشرفت نیز اعمال می‌شود.
- این پروژه به‌صورت modular و قابل توسعه طراحی شده تا در آینده بتوان آن را به یک سیستم بزرگ‌تر برای دانشگاه‌ها و مراکز آموزشی تبدیل کرد.

## توسعه آینده

در نسخه‌های آینده، این پروژه می‌تواند گسترش پیدا کند تا شامل موارد زیر شود:

- مدیریت چندین دانشگاه یا گروه آموزشی
- نقش‌های مختلف برای کاربران مانند دانشجو، استاد و مدیر آموزش
- گزارش‌های تحلیلی و نمودارهای پیشرفت بیشتر
- امکان جست‌وجو و فیلترپذیری بیشتر در درس‌ها و برنامه‌های درسی
- بهبود تجربه‌ی کاربری پنل ادمین
- پشتیبانی بهتر از نسخه‌های مختلف برنامه درسی

## یادداشت

اگر شما هم علاقه‌مندید این پروژه را توسعه دهید یا برای دوستان و هم‌دانشگاهی‌های خود با آن کار کنید، این پروژه به‌صورت ساده قابل استفاده و شخصی‌سازی است و هدف آن کمک به تجربه‌ی بهتر دانشجویان در مسیر فارغ‌التحصیلی است.
